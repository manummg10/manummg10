## 🧠 Sobre mí

Soy desarrollador Full Stack con pasión por el diseño limpio, la arquitectura de código mantenible y la resolución de problemas reales mediante software. Me enfoco en desarrollar experiencias de usuario fluidas en el frontend conectadas a APIs sólidas y bases de datos optimizadas.

- 🚀 **Especialidad:** Desarrollo web full stack, SPAs e integración de servicios REST / Cloud.
- 💻 **Stack principal:** React, Node.js, C#, .NET, MySQL y Tailwind CSS.
- 🧩 **Enfoque:** Código limpio, diseño funcional de interfaces e innovación constante.
